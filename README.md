# Required Environment Variables
The following environment variables are required for execution.
- POSTGRESQL_HOST
- POSTGRESQL_PORT
- POSTGRESQL_DATABASE
- POSTGRESQL_USERNAME
- POSTGRESQL_PASSWORD
